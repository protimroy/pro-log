# R10 protocol · Eight-character context at the R09 parameter budget

Written before the first R10 score was inspected. Reuse the verified Tiny Shakespeare source, character normalization, 100,000-character train prefix and contiguous development/test splits from R09. Score every arm on the same windows, starting at index eight within each split.

The assistant proposes a log-linear predictor. Start with a two-character interpolated Kneser–Ney model. Add budgeted three-character suffix corrections selected by training frequency. Pool distant-character evidence by adding smoothed lag-specific log likelihood ratios at lags 3–8, scaled by a single validation-selected weight. Each lag table reuses a row across all contexts with that character at that lag. Compare a short-context base, a suffix-only ablation, a lag-only ablation, and the combination. Select candidate and lag weight on validation. Fit every count statistic on the training split only.

Compile into fresh weights of a causal Transformer that routes eight positions to separate attention heads. Its ReLU units read reusable symbol and suffix indicators. Its target has at most 220,510 trainable parameters including all weights installed by the compiler. Verify direct and compiled probabilities across the full held-out set and independently sampled synthetic contexts.

Controls are single-discount interpolated Kneser–Ney with one through eight history characters, with a validation grid for discount and history length, and the identical randomly initialized Transformer trained with AdamW on the same training windows from three seeds. The count control's table size is measured and it has no neural parameter-budget constraint. Neural checkpoints are selected on a deterministic validation subset, and final scores use the full validation and test splits. Primary metric is held-out bits per normalized character. The design asks whether the longer-context program improves on its short-context base, whether the distant features contribute beyond suffixes, and how the resulting models rank against both controls.
